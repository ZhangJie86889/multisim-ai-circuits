# 占位符填写规范

[`circuit-generation-template.md`](./circuit-generation-template.md) 里共有 **12 个占位符**。
本文件给出每一个的**含义 / 填写规则 / 正例 / 反例**。
偷懒办法：去开一个 [circuit-request Issue](../.github/ISSUE_TEMPLATE/circuit-request.md)，
表单字段与下面 1~8 一一对应，复制粘贴即可。

## 1. `{{电路名称}}`

**规则**：`拓扑/功能 + 核心器件型号 + 关键指标`，20 字以内，别写"一个电路"。

- ✅ `2N2222 饱和开关驱动红色 LED（5 V / 约 3 mA）`
- ✅ `NE555 无稳态多谐振荡器（1 kHz 方波，占空比约 53%）`
- ❌ `三极管电路` / `帮我设计一个放大电路`

## 2. `{{验证仪器}}`

**规则**：用 Multisim 仪器代号，有多个就都写。

| 代号 | 仪器 | 典型用途 |
|------|------|---------|
| XSC1 | Oscilloscope 示波器 | 看波形、测幅值/周期/相位 |
| XMM1 | Multimeter 万用表 | 测静态直流工作点 |
| XBP1 | Bode Plotter 波特图仪 | 测幅频/相频、增益带宽 |
| XFG1 | Function Generator 函数发生器 | 产生激励（不算"验证"，但常一起写） |
| XDA1 | Distortion Analyzer | 测失真度 |

- ✅ `XSC1 双通道示波器 + XMM1 万用表`
- ❌ `示波器`（可以，但写代号 AI 会连端子和面板参数一起给，更省事）

## 3. `{{验证目标}}`

**规则**：`要看什么量` + `预期值`，越具体越好。

- ✅ `确认输入高电平时 Q1 进入饱和（Vce < 0.3 V），LED 电流约 3 mA；输入低电平时 LED 完全熄灭`
- ❌ `看看能不能工作`

## 4. `{{性能指标}}`

**规则**：量化 + 单位 + 边界（≥ / ≤ / 典型值）。

- ✅ `电压增益 |Av| ≥ 20（1 kHz、RL = 10 kΩ 时）；下限频率 ≤ 100 Hz；输出不削顶时最大不失真幅值 ≥ 2 V`
- ❌ `放大倍数大一点`

## 5. `{{电源规格}}`

**规则**：`单/双电源 + 电压 + 网络名`。

- ✅ `单电源 VCC = 5 V（网络名 VCC，对地）`
- ✅ `双电源 ±12 V（VCC = +12 V，VEE = -12 V）`
- ❌ `5 伏`

## 6. `{{输入信号}}`

**规则**：`波形 + 频率 + 幅值（标明 Vpp / Vpk / Vrms）+ 直流偏置`。

- ✅ `1 kHz 方波，0 V ~ 5 V（即 Vpp = 5 V、Offset = 2.5 V），占空比 50%`
- ✅ `1 kHz 正弦，20 mV 峰值，0 V 偏置`
- ❌ `输入一个信号`

## 7. `{{负载}}`

- ✅ `RL = 10 kΩ 阻性负载，接在输出耦合电容之后`
- ✅ `空载（仅示波器探头，1 MΩ // 30 pF）`
- ❌ `接个负载`

## 8. `{{有源器件及型号}}`

**规则**：型号必须能在 Multisim 主数据库里搜到，不确定先查
[`docs/multisim-library-map.md`](../docs/multisim-library-map.md)。

- ✅ `2N2222（NPN，Transistors / BJT_NPN）`
- ✅ `NE555 / LM555CN（Mixed / TIMER）`
- ❌ `S8050`（Multisim 默认库通常没有，得自己导模型）

## 9. `{{元器件清单：每行一个，含网表标号/Multisim库路径/参数}}`

**规则**：一行一个，**三列齐全**。标号遵循 SPICE 首字母规则
（R 电阻 / C 电容 / L 电感 / V 电源 / D 二极管 / Q 三极管 / X 芯片）。

```text
VIN  | Sources / SIGNAL_VOLTAGE_SOURCES / PULSE_VOLTAGE | PULSE(0 5 0 1u 1u 0.5m 1m)，1 kHz 方波
RB   | Basic / RESISTOR                                 | 10k
Q1   | Transistors / BJT_NPN / 2N2222                   | NPN，β ≈ 200
DLED | Diodes / LED / LED_red                           | Vf ≈ 2.0 V
RC   | Basic / RESISTOR                                 | 1k
VCC  | Sources / POWER_SOURCES / DC_POWER               | 5 V
GND  | Sources / POWER_SOURCES / GROUND                 | —
```

- ❌ `电阻若干、电容两个`（不行，AI 只能瞎猜标号和值）

## 10. `{{关键设计计算}}`

**规则**：**列公式和推导**，不要只给结论——AI 会照着你的算式填第 7 部分验证值表。

```text
1) 取 VCC = 5 V，LED_red 正向压降 Vf ≈ 2.0 V，2N2222 饱和压降 Vce(sat) ≈ 0.2 V
2) 目标 Ic(sat) ≈ 3 mA → RC = (5 - 2.0 - 0.2) / 3 mA ≈ 933 Ω，取标称 1k → Ic ≈ 2.8 mA
3) 取强制 β = 10（远小于 2N2222 的 β ≈ 200，保证深度饱和）→ Ib = 2.8 mA / 10 = 0.28 mA
4) RB = (5 - 0.7) / 0.28 mA ≈ 15k，取标称 10k → Ib = (5 - 0.7) / 10k = 0.43 mA
5) 校验：Ib × βmin = 0.43 mA × 100 = 43 mA >> 2.8 mA → 深度饱和，Vce ≈ 0.2 V ✅
```

## 11. `{{信号流向}}`

**规则**：从输入端子到输出端子，逐个元件说清楚"电流/信号怎么走"。

- ✅ `输入方波经 RB 限流进入 Q1 基极 → Q1 作为开关控制集电极回路 → 高电平时 Q1 导通，
     电流从 VCC 经 RC、DLED、Q1 的 C-E 到地，LED 点亮；低电平时 Q1 截止，回路断开，LED 熄灭`
- ❌ `从左到右`

## 12. `{{输入源→中间元件按流向→电源行放最后}}`

**规则**：这条决定 Multisim 导入后的**元件摆放顺序**（Multisim 按元件行出现顺序从左到右摆）。
直接把上面第 11 条翻译成**元件标号序列**，电源行永远放最后。

- ✅ `VIN → RB → Q1 → DLED → RC → VCC`
- ✅ `VIN → C1 → R1 → R2 → Q1 → RC → RE1 → RE2 → CE → C2 → RL → VCC`
- ❌ `VCC → RC → Q1 → RB → VIN`（电源打头，导入后整张图是反的）

> 💡 填完后，把同一串标号写进电路 `README.md` 的
> `<!-- SIGNALFLOW: VIN,RB,Q1,DLED,RC,VCC -->` 标记里，
> `scripts/cir_lint.py` 会自动比对网表行序与声明是否一致（不一致只报 warn，不阻塞 CI）。

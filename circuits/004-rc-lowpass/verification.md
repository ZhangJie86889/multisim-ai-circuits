## 3. 手算过程

```text
R = 1 kΩ
C = 100 nF
τ = R × C = 1,000 × 100 nF = 100 µs
fc = 1 / (2πRC) = 1 / (2π × 1,000 × 100 nF) = 1.59 kHz
|H(fc)| = 1 / sqrt(1 + (fc/fc)^2) = 0.707
φ(fc) = -atan(fc/fc) = -45°
|H(10 kHz)| = 1 / sqrt(1 + (10 kHz / 1.59 kHz)^2) = 0.157
```

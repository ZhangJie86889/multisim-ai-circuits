## 3. 手算过程（用网表元件值）

```text
VCC = 5 V, RA = 8.2k, RB = 68k, C = 10n

1) 目标频率
   f = 1.44 / ((RA + 2*RB) * C)
   需要 (RA + 2*RB) * C = 1.44e-3
   取 C = 10n -> RA + 2*RB = 144 kΩ
   取 RB = 68k -> RA = 144k - 136k = 8k -> 标称取 8.2k
   校核: RA + 2*RB = 8.2k + 136k = 144.2 kΩ
         f = 1.44 / (144.2k * 10n) = 1.44 / 1.442e-3 = 998.6 Hz   (偏差 -0.14 %)

2) 充放电时间
   tH = 0.693 * (RA + RB) * C = 0.693 * 76.2k * 10n = 528.1 µs
   tL = 0.693 * RB       * C = 0.693 * 68k  * 10n = 471.2 µs
   T  = tH + tL                                     = 999.3 µs
   f  = 1 / T                                       = 1000.7 Hz
   D  = tH / T = 528.1 / 999.3                      = 52.85 %

3) 电容电压阈值
   V_upper = 2/3 * VCC = 3.333 V
   V_lower = 1/3 * VCC = 1.667 V

4) 输出电平（NE555 双极输出级，典型值）
   VOH ≈ VCC - 1.3 = 3.7 V      （拉电流 5 mA 时可能降到 VCC - 1.7 = 3.3 V）
   VOL ≈ 0.1 V

5) 电流校核
   I_RL(peak)   = VOH / RL = 3.7 / 10k        = 0.37 mA
   I_DIS(peak)  = V_upper / RB = 3.333 / 68k  = 49 µA   （远小于 7 脚额定 50 mA）
   I_charge     = (VCC - V_lower) / (RA + RB) = 3.333 / 76.2k = 43.7 µA
```

**备注 / 已知问题**：

1. **本电路在纯 SPICE（如 ngspice / LTspice）里无法直接仿真** —— `XU1` 引用的 `NE555`
   模型不存在，且项目规则禁止 `.SUBCKT`。只有在 Multisim 里替换成库件后才能跑。
   这是有意为之的取舍：宁可诚实标注，也不用 `.SUBCKT` 破坏"可导入 Multisim"的硬约束。
2. 频率理论值 998.6 Hz 用的是忽略放电管 `Vce(sat)` 和传播延迟的近似公式，
   实测偏低 2~5 % 属正常。
3. 输出高电平**不是 5 V**，若实测接近 5 V，说明用的是 CMOS 555（TLC555/LMC555）模型，
   应在 verification 里注明实际使用的器件型号。
4. 若占空比需求 < 50 %，需在 RB 上反并联一个二极管（阳极接 THR、阴极接 DIS）——
   当前电路不含该二极管，故 D 只能 > 50 %。

## 3. 手算过程（用网表元件值）

```text
VCC = 12 V, R1 = 47k, R2 = 8.2k, Rc = 4.7k, RE1 = 100, RE2 = 900, RL = 10k
Vbe = 0.7 V, beta = 200, VT = 26 mV

[直流]
Vb  = 12 * 8.2k / (47k + 8.2k) = 12 * 8.2 / 55.2      = 1.783 V
Ve  = Vb - 0.7                                        = 1.083 V
Ie  = Ve / (RE1 + RE2) = 1.083 / 1000                 = 1.083 mA
Ic  = Ie * beta / (beta + 1) = 1.083 * 200 / 201       = 1.078 mA
Vc  = 12 - Ic * Rc = 12 - 1.078m * 4.7k               = 6.933 V
Vce = Vc - Ve = 6.933 - 1.083                         = 5.850 V
Ib  = Ic / beta                                       = 5.39 uA
分压电流 = 12 / 55.2k = 217 uA = 40 * Ib  ->  Q 点稳定

[交流]
re   = 26 mV / Ie = 26m / 1.083m                     = 24.0 Ω
空载 Av = -Rc / (RE1 + re) = -4700 / 124             = -37.9  (31.6 dB)
带载 Av = -(Rc||RL) / (RE1 + re) = -(4700||10000)/124 = -(3197)/124
                                                      = -25.8  (28.2 dB)   >= 20  OK
Rin  = R1 || R2 || [beta*(RE1+re)] = 47k || 8.2k || 24.8k
     = 6.98k || 24.8k                                = 5.44 kΩ
Rout ≈ Rc                                             = 4.7 kΩ

[下限频率]
Rth  = R1 || R2 = 47k || 8.2k                        = 6.98 kΩ
R(CE 支路) = RE1 + re + Rth/beta = 100 + 24 + 34.9    = 158.9 Ω
fL(CE) = 1 / (2*pi*158.9*100u)                        = 10.0 Hz   <- 主导
fL(C1) = 1 / (2*pi*5.44k*10u)                         = 2.93 Hz
fL(C2) = 1 / (2*pi*(4.7k+10k)*10u)                    = 1.08 Hz

[上限频率 - 粗估]
Cm   = Cjc*(1+|Av|) = 8p * (1 + 37.9)                 = 311 pF
fH   ≈ 1 / (2*pi*Rth*Cm) = 1 / (2*pi*6.98k*311p)      ≈ 73 kHz   (模型相关)

[动态范围]
ΔV+ = VCC - Vc = 12 - 6.93                            = 5.07 V  (截止限制)
ΔV- = Vc - (Ve + Vce_sat) = 6.93 - 1.28               = 5.65 V  (饱和限制)
最大不失真输出峰值 ≈ 5.07 Vp -> 最大输入峰值 = 5.07 / 25.8 = 196 mVp
```

**备注 / 已知问题**：

1. 上限频率 `f_H` 强依赖 Multisim 库里 2N2222 的 `Cje/Cjc/TF` 参数，理论值 73 kHz 只是
   用网表 `.MODEL` 参数算的。黑盒替换成库件后请以 `.AC` 实测为准，两者差 2~3 倍属正常。
2. 增益理论值用 `β = 200` 算，实际 2N2222 的 β 分散范围大（100~300），
   `Ic` 与 `Vc` 会有 ±10% 波动，但 `Av` 由 `RE1` 主导，受 β 影响很小——这正是留 `RE1` 的意义。
3. 若实测增益明显低于 25.8，优先怀疑 **CE 未起作用**（见 README 第 7.2 节第 3 条）。
